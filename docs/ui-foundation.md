# VietSoft UI Foundation

This branch introduces an isolated frontend foundation spike.

## Stack

- Vite
- TypeScript
- Tailwind CSS
- Lucide
- No React
- No jQuery

## Scope

Only build/tooling and an isolated visual preview are introduced. Existing QR generation, history, import/export, print, authentication, license, cloud sync, Supabase, and production HTML are untouched.

## Local validation

npm install
npm run dev

Open /ui-foundation.html.

Then run:

npm run build
npm run preview

The branch is based directly on the production gh-pages branch.

# VietSoft QR — AI Project Instructions

Before changing code, read `docs/README.md` and `docs/ai-rules.md`.

For behavior-changing work:
1. Identify the affected workflow.
2. Read the relevant architecture, integration, data, and UX documentation.
3. Use `docs/document-map.yml` for impact analysis.
4. Do not guess when documentation and code conflict.
5. Update affected documentation in the same change.
6. Validate the workflow and perform a documentation consistency audit.

The `docs/` directory is the project knowledge source of truth. Code is implementation, not the authority for undocumented intent.
